# Bank Marketing Classification (WEKA Analysis)

## Overview
Analyzed a bank marketing dataset using multiple machine learning classifiers in WEKA to predict whether a customer will subscribe to a financial product.

## Objective
Evaluate and compare different classification models to determine the most effective approach for predicting customer responses.

## Dataset
- Bank Marketing Dataset (ARFF format)
- Contains customer demographic and financial attributes
- Target: YES (subscribed) vs NO (not subscribed)

## Methods
Used WEKA to train and evaluate multiple classifiers:
- Decision Table
- Naive Bayes (Bayes Net)
- Logistic Regression
- Support Vector Machine (SMO)
- k-Nearest Neighbors (IBk)

## Results
- Bayes Net achieved ~63% accuracy  
- Logistic Regression achieved ~61% accuracy  
- Decision Table showed lower performance with higher error rates  
- KNN achieved ~70% classification accuracy  

## Key Insights
- Simpler probabilistic models performed consistently across the dataset  
- Model performance varied depending on feature relationships  
- Highlights importance of model selection in financial prediction tasks  

## Tools & Technologies
- WEKA  
- ARFF datasets  
- Machine Learning Classification  

## Business Impact
- Helps banks target customers more effectively  
- Improves marketing efficiency  
- Reduces cost of unsuccessful campaigns
